## Getting Started

- Be sure to install all of the dependencies by running "pip install -r requirements" and then running:
  python manage.py makemigrations
  python manage.py migrate
  python manage.py createsuperuser

### Dependencies

- All of the dependencies are listed inside of 'requirements.txt'

### Installing

- Run 'git clone https://github.com/BrennanA757/miniproject8BrennanAdams.git' and 'cd miniproject8miniproject8BrennanAdams'

### Executing program

- Be sure to run:
  python manage.py makemigrations
  python manage.py migrate
  python manage.py createsuperuser

To create the datasets and then run

python manage.py runserver

to initiate the program.
